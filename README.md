# IT Group — landing page

Вёрстка лендинга IT Group: чистые HTML, CSS и JavaScript, без сборщиков и фреймворков.

## Что внутри

| Путь | Назначение |
|---|---|
| `index.html` | вся страница |
| `css/` | стили: по файлу на секцию плюс общие (`base`, `anim`, `modal`, `navmenu`, `mega`) |
| `js/main.js` | вся логика: липкая шапка, меню, слайдер отзывов, появление по скроллу, счётчики, попап |
| `images/` | картинки и SVG |
| `design/` | исходные макеты |
| `server.py` | локальный сервер для разработки (отдаёт файлы без кеширования) |

## Запуск

```bash
python3 server.py 5173
```

Затем откройте http://127.0.0.1:5173

## Особенности

- Адаптив от 320px: точки 1500 / 1200 / 1024 / 768 / 576px
- Именование классов по BEM
- Появление блоков привязано к прокрутке и работает в обе стороны
- Фоновые анимации останавливаются, когда уходят за пределы экрана
- Учитывается системная настройка «уменьшить движение»
